# tebak-kata

Gambar soal game **Tebak Kata** bot Vanillate.ID. Tiap soal satu berkas `<id>.webp` (1280 x 720, id acak 6 karakter).
Repo ini PUBLIK: **jawaban dan rumus soal tidak ada di sini** (ada di repo bot yang privat).

- Panduan membuat ikon benda tambahan: `INSTRUKSI-GPT.md`.
- Pembuat gambar soal: `tools/tebakkata_render.py` (membaca spesifikasi privat lewat `--spec`, memakai ikon `tebak-gambar/<id>-3.webp`).
- Jangan menimpa atau menghapus berkas pada commit yang sudah dipakai bot. Soal baru = berkas baru, lalu bot dikunci ke SHA commit yang baru.
